# geyman-vankessel-ptsp-multiomics

[![DOI](https://zenodo.org/badge/1417790341.svg)](https://doi.org/10.5281/zenodo.24288965)

This repository contains the complete bash preprocessing and R statistical pipelines used for the transcriptomic and DNA-binding analyses in:

> **A Multi-Omic Framework Challenges Canonical Mechanisms of Quorum Sensing Inhibition in Vibrio**  
> Logan J. Geyman, Chase M. Mullins, Tanmaya A. Rasal, Lydia Feddolino, and Julia C. van Kessel
> *[Journal Name]*, 2026. DOI: [Insert Paper DOI]

The pipeline integrates bulk RNA-seq, SmcR TF ChIP-seq, and RNAP ChIP-seq to evaluate the small-molecule quorum sensing inhibitor PTSP across *Vibrio* pathogens.

## Repository Structure

```text
├── README.md
├── LICENSE
├── envs/                                     # Conda and R environment templates
│   ├── chipseq_env.yml
│   ├── r_sessioninfo.txt
│   └── rnaseq_env.yml
├── refs/                                     # Genome, GTF, and Motif databases (User populated)
├── raw_fastq/                                # Raw sequence data and metadata (User populated)
├── 01_sequencing_data_processing/            # Raw read alignment and peak processing
│   ├── chipseq_pipeline.sh
│   ├── macs2_consolidation.R
│   ├── memeChIP_analysis.sh
│   └── rna_seq_pipeline.sh
└── 02_data_analysis/                         # Statistical modeling and figure generation
    ├── alpha_rpoB_ChIP_analysis.R
    ├── alpha_smcR_ChIP_analysis.R
    ├── induced_fit_model_analysis.R
    └── rna_seq_analysis.R

Before running, populate the refs/ directory with the reference genomes (.fna), annotation (.gtf), and CollecTF motif database (collectf.meme). Place raw sequencing reads in raw_fastq/.
Activate the respective conda environments and execute the scripts from the repository root:
# RNA-seq processing
conda activate rnaseq_env
bash 01_sequencing_data_processing/rna_seq_pipeline.sh

# ChIP-seq processing
conda activate chipseq_env
./01_sequencing_data_processing/chipseq_pipeline.sh
01_sequencing_data_processing/macs2_consolidation.R
./01_sequencing_data_processing/memeChIP_analysis.sh

2. Statistical Modeling & Figure Generation (R)
The R scripts are designed to run sequentially and will dynamically locate the outputs generated by the preprocessing pipelines. Open the repository root as your working directory (or use an .Rproj file) and run:
02_data_analysis/rna_seq_analysis.R: Computes RNA-seq DEGs, performs global DBSCAN potency analysis, and evaluates transcriptomic incomplete penetrance.
02_data_analysis/alpha_smcR_ChIP_analysis.R: Evaluates SmcR occupancy shifts across functional tiers using NCIS/SES deep background calibration.
02_data_analysis/alpha_rpoB_ChIP_analysis.R: Computes RNAP promoter vs. coding body decoupling and integrates RNAP shifts with RNA-seq fold changes.
02_data_analysis/induced_fit_model_analysis.R: Fits Linear Mixed-Effects Models to evaluate the impact of sequence symmetry on binding dynamics.
